Ollama setup & connection help

Install Ollama on this computer and run ollama pull gemma3:1b once. No model is downloaded by this app.

For a hosted deployment, set OLLAMA_ORIGINS to that site's exact origin in Ollama. Local AI is still performed on your computer.

On Windows, add OLLAMA_ORIGINS to your user environment variables. Use downloaded local models and optionally disable Ollama cloud features with OLLAMA_NO_CLOUD=1.

Writing and saving remain available without AI. localhost on a phone refers to the phone, not your computer.
